## 概覽

開啟面板的第一頁（「概览」），一眼看清整體狀況：

- **使用中的使用者 / 總數、目前線上、線上節點 / 總數、入站數、累計流量**；
- **需要处理**：快到期、剛到期、流量快用完的使用者數量，點一下跳到使用者頁；
- **近 14 天流量圖**；
- **各節點流量**：每台節點的狀態、本週期上行下行、下次統計重設時間、近 14 天和累計流量，用量最多的排在最前面。

## 使用者

（介面：「用户」）一個使用者就是一個客戶帳號，對應一條訂閱連結。

### 新建使用者

| 欄位 | 說明 |
| --- | --- |
| 名称 | 1–32 個字元，可用字母（包含中文）、數字、點、橫線、底線，以字母或數字開頭。名稱在所有節點上都用來統計流量 |
| 套餐 | 選一個[套餐](#套餐)，會自動填好下面幾項，填好後還能修改 |
| 有效天数 | 從現在起算幾天後到期。和「到期」都填時，以「到期」為準 |
| 到期 | 具體的到期時間（依伺服器時區）。留空表示長期有效 |
| 流量上限 GiB | 留空或填 0 表示不限。1 GiB = 1024³ 位元組 |
| 同时在线 IP | 最多允許幾個不同的來源 IP 同時使用，留空表示不限，見下文 |
| 流量重置 | 月付方案用：每月哪天把已用流量歸零。可選「按创建日」「每月 N 号」「每月最后一天」 |
| 重置时间 | 重設在當天幾點幾分進行 |
| 备注 | 只有你看得到 |

關於流量重設：選 29、30、31 號時，較短的月份會自動順延到該月最後一天，不會跳過二月。到期和重設落在同一時刻時，以到期為優先，不會因為重設而恢復可用。

使用者到期後，已用流量也會自動歸零（不論有沒有設定重設日），續費時從 0 開始計算；歷史流量統計不受影響。既沒有到期時間、也沒有重設日的使用者，依建立時間每月自動歸零一次（例如 3 月 14 日 09:30 建立，就是每月 14 日 09:30）。

### 使用者列表

每一列顯示：

- **狀態**：`正常`；`已停用`（你手動停用的）；`已失效`（到期或流量用完）。使用者此刻有連線時，還會顯示 `在线`。
- **可用协议**：`全部` 表示能用所有入站；`3 / 8` 表示只開放其中 3 個。點它可以修改，見下文。
- **IP**：目前線上 IP 數 / 上限。超出時標紅。
- **到期**、**已用**、**上限**：上限下面會顯示已用百分比，以及下次自動重設的時間。

名稱下方的連結：

- **活动**：這個使用者最近的使用情形，見下文。
- **打开订阅**、**复制链接**：訂閱連結。
- **二维码 / 话术**：展開訂閱 QR Code，以及一段可以直接傳給客戶的文字（訂閱連結、到期時間、流量、使用方法）。傳送前可以先修改，再點「复制话术」。

列尾的按鈕：

| 按鈕 | 作用 |
| --- | --- |
| 编辑 | 修改名稱、到期、流量上限、IP 上限、重設日、備註。已用流量不在這裡改 |
| 续费 | 見下文 |
| 停用 / 启用 | 停用後客戶立即無法連線，訂閱裡會顯示「账号已停用」 |
| 清零 | 把已用流量歸零 |
| 重置链接 | 替這個使用者換一條新的訂閱連結和新密碼，見下文 |
| 删除 | 刪除使用者，訂閱立即失效 |

### 需要處理

使用者列表上方會自動列出這些啟用中的使用者，最緊急的排在最前面，每條後面都有「续费」按鈕：

- 7 天內要到期的；
- 30 天內已經到期的；
- 流量用到 90% 以上的（月付使用者會註明哪天自動重設）。

被你手動停用的使用者不會出現在這裡。

### 續費

點「续费」，填天數（也可以依套餐選），選擇是否把已用流量歸零，然後確認：

- 新的到期時間 = **目前到期時間和現在之中較晚的那個** + 續費天數。提前續費，剩下的天數照算；過期後再續，從現在開始算，過期那幾天不補。
- 續費會自動**啟用**帳號。
- 不限期的使用者續費不會加上到期時間，只依勾選歸零流量。
- 訂閱連結不變，客戶不用做任何事。

### 重設連結

（介面：「重置链接」）用於**某個使用者的連結外洩、被轉賣**的情況。點了之後：

1. 訂閱連結換成新的，舊連結立即失效；
2. 連線密碼也全部更換，用舊連結匯入的節點立即連不上。

所以要把**新連結**傳給這個使用者，請他刪掉舊訂閱、**重新匯入**（只點「更新訂閱」沒用，因為舊連結已經失效）。其他使用者完全不受影響。

> 只是想讓客戶重新整理節點列表時，**不要**點這個，請他在用戶端裡點「更新訂閱」就好。

### 可用協定（入站分配）

點使用者列裡的「全部」或「3 / 8」進入：

- **全部入站（含以后新建）**：不限制，以後新建的入站也自動能用；
- **仅允许勾选项**：只能用勾選的入站，以後新建的入站不會自動加入。

上方可以「全选当前入站 / 清空勾选」，每台節點也可以「全选 / 取消 / 仅选此节点」。例如只開放日本節點：在日本那一組點「仅选此节点」，再儲存。不能儲存為一個都不勾；要完全禁止使用，請停用使用者。

### 同時線上 IP

依**不同的來源 IP** 計數，不是依連線數（一台裝置會開幾十條連線）。

- 超出上限時，**後連上來的那個 IP 會被斷開**，先在使用的不受影響。
- 一個 IP 斷開後，名額會**再保留 1 分鐘**。手機鎖定螢幕、斷線重連都不會掉名額；從 Wi-Fi 切到行動網路時，最多卡 1 分鐘左右。
- **每台節點各自計數**。上限設 2 的使用者，在兩台節點上各用 2 個 IP 是允許的。所以使用者列表顯示的 IP 數（各節點的總和）可能大於上限。
- 經過中轉的連線，節點看到的都是中轉機的位址，這時 IP 限制會變寬鬆，但不會誤傷。

### 活動

顯示使用者每小時的**使用型態**：並行連線數、不同目標位址數、不同目標連接埠數、來源 IP 數，取每小時的峰值。

**不記錄使用者造訪了哪些網站**，節點不回報，面板也不儲存。型態就足以判斷異常：一般瀏覽只連少數幾個主機；BT 下載會同時連上百個不同的位址；長時間大量下載則是「目標少 + 流量大」，可以對照流量一起看。

## 套餐

把常賣的組合存成預設，例如「月付 100G / 3 個 IP / NT$150」。

| 欄位 | 說明 |
| --- | --- |
| 名称 | 例如「月付 100G」，支援中文和空格 |
| 有效天数 | 留空或 0 表示不限期 |
| 流量上限、同时在线 IP、流量重置 | 同使用者 |
| 备注 | 例如價格，會顯示在下拉選單裡 |

新建使用者或續費時選一個套餐，表單就會自動填好，填好後還能修改。**使用者和套餐之間不保留關聯**：改價、改流量、刪除套餐，都**不會影響已經開出去的帳號**。

## 節點

（介面：「节点」）一台代理伺服器就是一個節點。安裝方法請見[安裝](install.md#3-登記並安裝節點)。

| 欄位 | 說明 |
| --- | --- |
| 名称 | 支援中文。節點改名時，會自動依新名稱重新產生它所有入站的名稱 |
| 客户端连接地址 | 訂閱裡用戶端要連線的位址（網域或 IP）。換伺服器時只要改 DNS，不用重發訂閱 |
| 国家 | 兩位國家代碼 |
| 流量倍率 | 扣多少套餐流量，見下表 |
| 订阅排序 | 數字越小，在訂閱裡越前面（編輯時可改） |
| 节点统计重置 | 概覽頁「本周期」流量每月幾號幾點歸零。只影響統計，不影響使用者套餐和歷史紀錄 |

**流量倍率**，以客戶在這台節點上實際用了 100 GB 為例：

| 倍率 | 扣多少套餐流量 |
| --- | --- |
| `1` | 100 GB |
| `0.5` | 50 GB |
| `0` | 0 GB（不扣，但帳號停用、到期、流量用完時依然不能用） |
| `2` | 200 GB |

可填 0 到 100，最多三位小數。實際流量照常記錄；改倍率只影響之後的流量，不會重算以前的，也不會重新啟動節點。

列表中的其他資訊和按鈕：

- **狀態**：`在线` / `离线` / `已停用`。
- **入站**：入站數量，點進去管理這台節點的入站。
- **版本**：節點程式版本 / 核心版本。
- **换 token**：產生新的接入 token，舊的立即失效。之後要把新 token 寫進節點伺服器的 `/opt/skysbx/node.env`（`SKYSBX_TOKEN=` 那一行），再執行 `systemctl restart skysbx-node`。
- **停用**：節點不再接受連線，也不會出現在訂閱裡。

## 入站

一個入站就是節點上的一個代理連接埠，在用戶端裡顯示為一個節點。在節點列表點「入站」數量進入。

### 協定

| 協定 | 範例連接埠 | 防火牆要放行 | 要填的 | 適合 |
| --- | --- | --- | --- | --- |
| VLESS Reality | 443 | TCP | Reality 握手站點 | **主力**，最穩，不需要憑證 |
| Hysteria2 | 8443 | UDP | 憑證、SNI；可選混淆、偽裝網站、跳連接埠 | 速度快；網路干擾 QUIC 時開混淆 |
| AnyTLS | 8443 | TCP | 憑證、SNI | 備用 |
| Shadowsocks 2022 | 8388 | TCP 和 UDP | 無（金鑰自動產生） | 備用，相容性最好 |
| TUIC v5 | 9443 | UDP | 憑證、SNI | 通常不需要：功能是 Hysteria2 的子集（沒有混淆、偽裝、跳連接埠） |

建議每台節點至少開一個 **TCP** 協定（VLESS Reality）和一個 **UDP** 協定（Hysteria2），客戶遇到哪種網路問題都有一個能用。

所有金鑰、short id、Shadowsocks 的伺服器端金鑰都自動產生。

### 通用欄位

- **tag（入站名稱）**：用戶端裡顯示的名字，例如「香港 01」，支援中文，整個面板內不能重複。
- **端口**：同一台節點上同一個 TCP 連接埠不能被兩個入站佔用。和面板裝在同一台機器時，要避開 80 和 443。
- **证书路径、私钥路径**：節點伺服器上的檔案位置，留空就是安裝腳本放的 `/opt/skysbx/cert.pem` 和 `key.pem`。
- **SNI**：和節點憑證相符的網域，通常就是節點網域。
- **节点内排序**（編輯時可改）：同一節點內的排列順序，數字越小越前面。只改排序不會重新啟動節點。

### VLESS Reality 的握手站點

Reality 會借用一個真實網站的 TLS 握手來偽裝。可以從輸入框旁的「常用站点…」下拉選單選，也可以自己填 `網域:連接埠`。

點「**检测**」會從面板確認這個網站支援 TLS 1.3 和 HTTP/2、憑證正常。檢測通過只代表從面板連得上，不代表每個地區都好用；檢測不通過的網站一定不能用。

### Hysteria2：混淆和偽裝網站

兩個功能防的是兩種不同的情況：

- **混淆（salamander）**：替每個封包再包一層，讓流量**看起來不像 QUIC**。適合「HY2 時好時壞、常常逾時，換成 Reality 就正常」的情況，也就是客戶的網路在限速或干擾 QUIC。混淆密碼自動產生並寫進訂閱，Clash Verge / mihomo、sing-box、Shadowrocket 都支援。
- **偽裝網站**：有人用瀏覽器或探測程式連到這個連接埠時，看到的是這個網站（例如 bing.com），而不是暴露代理身分的錯誤訊息。只影響伺服器端，用戶端不用變。可以從下拉選單選、點「随机」，或填任意 https 網址；不同入站最好用不同的網站。

**兩者是二選一生效的**：開了混淆，探測者連握手都完成不了，到不了偽裝網站那一步，所以偽裝填不填都可以（留著無妨，以後關掉混淆就會生效）。

| 情況 | 選擇 |
| --- | --- |
| HY2 常常逾時，Reality 正常 | 開混淆 |
| HY2 正常，只想更不容易被辨識 | 不開混淆，填偽裝網站 |

### Hysteria2 跳連接埠

例如：監聽 `8443`，跳躍範圍 `20000-30000`，間隔 `30s`。用戶端會在這個範圍裡不斷換連接埠，避開對單一 UDP 連接埠的限速。

1. 雲端安全群組放行 UDP 8443 和 UDP 20000–30000，本機防火牆允許 UDP 8443；
2. 節點會自動把整個範圍轉發到監聽連接埠（需要 nftables，安裝腳本已裝好）；
3. 客戶更新訂閱。

範圍可以寫 `20000-30000,40000`，不能和其他入站或中轉連接埠重疊。清空範圍就是關閉。只支援直連的 Linux 節點，不能和中轉一起使用。

### 中轉

兩種方式，擇一使用：

- **站内中转**：選另一台由面板管理的節點當中轉機，面板會自動在它上面開一個轉發連接埠，把流量原封不動轉到本節點。不解密、不認證，所以流量統計、IP 限制、活動紀錄都不受影響。修改中轉只會重建中轉機的設定。
- **外部中转地址**：中轉機不歸面板管理（例如自己設定的 realm、nginx stream），填 `relay.example.net:443`，帶上中轉機監聽的連接埠。

### 狀態

| 狀態 | 意思 |
| --- | --- |
| `已生效` | 節點正以最新的設定執行這個入站 |
| `确认中…` | 設定剛送給節點，頁面會自動重新整理等它確認 |
| `等待节点应用` | 節點還在用舊的設定，一直沒跟上 |
| `跑的是旧配置` | 節點拒絕了最新的設定，仍在執行上一份，頁面上方會顯示原因 |
| `未生效` | 節點沒有執行這個入站，請看頁面上方的錯誤和節點日誌 |
| `节点离线` | 節點沒連上面板，無法確認 |

### 修改入站的注意事項

- 新增、修改、停用任何入站，都會**重建這台節點的設定，節點上所有客戶都會斷線一次**。
- **改握手站點、開關混淆、改連接埠，客戶在更新訂閱之前會一直連不上。**正在使用的入站不要直接改：新建一個入站和舊的並行一兩週，大部分客戶更新過訂閱後再停用舊的。
- 改偽裝網站、改憑證路徑、改名稱、改排序不影響用戶端。

## 限制

（介面：「限制」）對**所有節點、所有使用者**生效的使用限制：

- **禁止 BT / PT**：能擋下明文 BT、uTP 和 UDP tracker，也就是大部分 BT 流量；擋不住走 TCP 的加密 BT。效果是讓 BT 很難用，不是完全不能用。
- **禁止测速站点**：依網域攔截常見的測速網站。
- **自定义域名黑名单**：每行一個，依後綴比對。寫 `example.com` 會連 `a.b.example.com` 一起擋掉。

儲存會對**所有節點**推送新設定，所有連線會斷一次。開啟任何一項後，節點會檢查每條連線開頭的幾個位元組來判斷協定和網域。

「大量下載」沒有開關，它是用量問題，請用使用者的流量上限和同時線上 IP 來管理。

## 設定

（介面：「设置」）

### 面板訪問路徑、根網域跳轉

請見[安裝：隱藏後台網址](install.md#隱藏後台網址建議)。

### 訂閱公告

（介面：「订阅公告」）每行一條（最多 5 行，每行不超過 60 個字），會顯示在**每個客戶訂閱的節點列表最上面**，例如「📢 官網：example.com」「續費請聯絡：xxx」。留空儲存就是關閉。

公告是連不上的假節點，只用來顯示文字。在 Clash、sing-box 裡，公告單獨放在最上面的「公告」群組，**不會進入任何實際承載流量的群組**，客戶不會誤連。客戶要更新訂閱才看得到新公告。公告不能和群組同名（如「AI」「节点选择」），同名的那行會被略過。

### 更換網域

在「设置 → 更换域名」裡填新的面板網域（和訂閱網域，可選），點「更换域名」。

1. **先**在網域服務商那裡把新網域的 A 記錄指向面板伺服器。面板會檢查解析，沒指向這台伺服器會提示你，不會儲存。用了 CDN 或檢查誤報時，可以勾「跳过解析检查」；
2. 儲存後面板自動重啟，十幾秒到一兩分鐘後用新網域開啟（第一次要申請憑證）。新網域暫時打不開時，舊位址仍然可以登入；
3. 節點會自動改連新網域，並記到節點自己的設定裡，**不用登入節點伺服器**。需要節點是這個版本或更新的，舊節點先升級；
4. 面板伺服器上的那台節點，如果位址就是面板網域，會自動換成新網域和新憑證。用它的 AnyTLS、Hysteria2、TUIC 的客戶要**更新一次訂閱**；
5. 新複製的訂閱連結都是新網域。**舊網域繼續保留**，已經發出去的舊訂閱連結照樣能用。

等節點都切過去（頁面會顯示還有幾個節點連著舊網域）、客戶都換了新連結，再點「停用旧域名」。停用後舊網域上的連結失效，面板也不再替它續憑證。舊網域被封或過期了也沒關係，它保留著只是不起作用。

### 兩步驟驗證

（介面：「两步验证」）開啟後，登入除了密碼，還要輸入手機驗證器（Google Authenticator、Microsoft Authenticator、1Password 等）上的 6 位數字。

1. 點「开启两步验证」，用驗證器掃描 QR Code；
2. 輸入驗證器顯示的 6 位數字確認。輸入正確之前不會生效，掃錯了也不會把自己鎖在外面；
3. **保存好頁面顯示的 10 組復原碼**，只顯示這一次。手機遺失時，每組復原碼可以代替驗證碼登入一次。

關閉兩步驟驗證或重新產生復原碼，都需要輸入目前的驗證碼。**手機和復原碼都遺失**時，在面板伺服器上執行：

```bash
/opt/skysbx/skysbx-panel -db /opt/skysbx/skysbx.db -reset-2fa
```

或執行 `veyra` 選單 → Panel → 7。

### 強制全員更新訂閱

（介面：「强制全员更新订阅」）緊急情況用的按鈕，**平時不要點**。需要輸入「全部断连」確認。

- 所有使用者的連線密碼全部更換，**訂閱連結不變**；
- 每台節點重建設定，所有連線中斷；
- 客戶在用戶端點「更新訂閱」後恢復。很多用戶端會自動更新（面板建議的間隔是 12 小時），沒有手動更新的客戶最多可能斷線 12 小時左右，所以最好事先通知客戶。

適合：懷疑某台節點伺服器被別人取得、刪掉了一台不再信任的節點、懷疑大量設定外洩。

| 情況 | 用哪個 |
| --- | --- |
| **某一個**使用者的連結外洩 | 使用者頁的「重置链接」 |
| 懷疑**所有人**的設定都外洩 | 強制全員更新訂閱 |
| 只是想讓客戶重新整理節點列表 | 都不用，請客戶自己點「更新訂閱」 |

## 訂閱和用戶端

### 匯入

把使用者的訂閱連結貼到用戶端，以「訂閱」的方式匯入並更新。面板會依用戶端自動選擇格式，也可以在連結後面加參數指定：

| 用戶端 | 匯入方式 | 指定格式 |
| --- | --- | --- |
| Clash Verge / Clash Party / mihomo | 匯入遠端訂閱 | `?format=clash` |
| sing-box | 遠端設定 | `?format=singbox` |
| Shadowrocket（小火箭） | 新增訂閱 | `?format=shadowrocket` |
| v2rayN 等 | 新增訂閱群組 | `?format=base64` |

用瀏覽器開啟訂閱連結看到的是一串 Base64 文字，這是正常的。

### 訂閱裡有什麼

- 使用者能用的所有入站，依節點的「订阅排序」和入站的「节点内排序」排列；
- Clash 和 sing-box 格式裡有一套現成的群組和分流規則，見下方的[群組和分流](#群組和分流)；
- 已用流量、總流量和到期時間：多數用戶端會顯示在訂閱資訊裡，小火箭顯示為「上傳 / 下載 / 總量 / 到期」；
- 設定了[訂閱公告](#訂閱公告)時，公告排在最前面。

帳號停用、到期或流量用完時，訂閱仍可正常更新，但裡面只有一條寫著原因的提示（例如「已于 2026-11-10 到期，请联系续费」），後面接著訂閱公告。客戶一看就知道該聯絡你，不會以為軟體壞了。

### 群組和分流

Clash 和 sing-box 格式的訂閱內建以下群組，客戶可以在用戶端裡逐一切換。群組名稱照介面原文顯示：

| 群組 | 預設 | 負責的流量 |
| --- | --- | --- |
| 公告 | — | 只在設定了訂閱公告時出現，只用來顯示文字 |
| 节点选择 | 第一個節點 | 主開關，列出全部節點 |
| AI | 跟隨节点选择 | ChatGPT、Claude、Gemini 等 |
| YouTube | 跟隨节点选择 | |
| Netflix | 跟隨节点选择 | |
| 谷歌 | 跟隨节点选择 | 搜尋、Gmail、Google Play 等 |
| 苹果 | 直連 | App Store、iCloud、系統更新 |
| 微软 | 直連 | Windows 更新、Office、Bing 等 |
| 漏网之鱼 | 跟隨节点选择 | 以上都沒比對到的其他流量 |

- **中國大陸網站和 IP 固定直連**，不經過節點，不消耗方案流量；區域網路位址也直連。GitHub 跟隨「节点选择」。
- 沒有「自動選擇」：節點故障時不會自動切換，客戶需要手動換一個。
- 每個群組各自選節點，各自負責自己的流量。例如 AI 選美國、Netflix 選新加坡、其他走香港時，三個節點同時在用；流量依各節點的倍率計算後，扣的是同一個方案。
- 分流規則來自 [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat)。用戶端透過訂閱網址下的 `/sub/rules/` 從面板下載規則檔，每天自動更新；面板每 12 小時從 GitHub 同步一次。所以客戶連不上 GitHub 也不影響，你不需要維護任何名單。
- Shadowrocket 和 v2rayN 使用分享連結，無法攜帶群組和規則，分流由用戶端自己的設定決定（v2rayN 內建「繞過大陸」，Shadowrocket 可以另外新增規則設定）。

### 安全

訂閱連結就等於帳號密碼：Base64 不是加密，拿到連結的人可以直接匯入使用。不要公開分享。連結外洩時用「重置链接」。

### 獨立的訂閱網域

安裝時可以設定一個獨立的訂閱網域（例如 `sub.example.com`）。設定後，只有這個網域能存取訂閱，存取它的其他路徑（包括 `/login`）都回傳 404；面板後台仍然用面板網域。

## 哪些操作會斷線

| 操作 | 影響 |
| --- | --- |
| 新增 / 修改 / 停用使用者、續費、歸零、重設連結 | 不會重新啟動任何東西，其他人的連線照常 |
| 改節點的倍率、連線位址、排序、統計重設 | 不影響連線 |
| 節點改名（會連帶重新命名它的入站） | 這台節點上所有連線斷一次 |
| 新增 / 修改 / 停用入站 | 這台節點上所有連線斷一次 |
| 儲存「限制」頁 | 所有節點的所有連線斷一次 |
| 強制全員更新訂閱 | 所有連線中斷，客戶更新訂閱後才能恢復 |
| 升級面板 | 後台幾秒鐘打不開，**客戶連線不受影響** |
| 升級節點 | 這台節點的連線斷一次 |
