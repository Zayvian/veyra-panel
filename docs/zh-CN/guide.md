## 概览

打开面板的第一页，一眼看清整体情况：

- **在用用户 / 总数、当前在线、在线节点 / 总数、入站数、累计流量**；
- **需要处理**：快到期、刚到期、流量快用完的用户数量，点一下跳到用户页；
- **近 14 天流量图**；
- **各节点流量**：每台节点的状态、本周期上行下行、下次统计重置时间、近 14 天和累计流量，用得最多的排在最前。

## 用户

一个用户就是一个客户账号，对应一条订阅链接。

### 新建用户

| 字段 | 说明 |
| --- | --- |
| 名称 | 1–32 个字符，可以用字母（包括中文）、数字、点、横线、下划线，以字母或数字开头。名称在所有节点上都用来统计流量 |
| 套餐 | 选一个[套餐](#套餐)，会自动填好下面几项，填好后还能改 |
| 有效天数 | 从现在算起多少天后到期。和「到期」都填时，以「到期」为准 |
| 到期 | 具体的到期时间（按服务器时区）。留空表示长期有效 |
| 流量上限 GiB | 留空或填 0 表示不限。1 GiB = 1024³ 字节 |
| 同时在线 IP | 最多允许几个不同的来源 IP 同时使用，留空表示不限，见下文 |
| 流量重置 | 月付套餐用：每月哪天把已用流量清零。可以选「按创建日」「每月 N 号」「每月最后一天」 |
| 重置时间 | 重置在当天几点几分进行 |
| 备注 | 只有你能看到 |

关于流量重置：选 29、30、31 号时，短的月份会自动顺延到该月最后一天，不会跳过二月。到期和重置落在同一时刻时，到期优先，不会因为重置而恢复可用。

用户到期后，已用流量也会自动清零（不管有没有设重置日），续费时从 0 开始算；历史流量统计不受影响。既没有到期时间、也没有重置日的用户，按创建时间每月自动清零一次（例如 3 月 14 日 09:30 创建，就是每月 14 日 09:30）。

### 用户列表

每一行显示：

- **状态**：`正常`；`已停用`（你手动停用的）；`已失效`（到期或流量用完）。用户此刻有连接时，还会显示 `在线`。
- **可用协议**：`全部` 表示能用所有入站；`3 / 8` 表示只开放了其中 3 个。点它可以修改，见下文。
- **IP**：当前在线 IP 数 / 上限。超出时标红。
- **到期**、**已用**、**上限**：上限下面会显示已用百分比，和下次自动重置的时间。

名字下方的链接：

- **活动**：这个用户最近的使用情况，见下文。
- **打开订阅**、**复制链接**：订阅链接。
- **二维码 / 话术**：展开订阅二维码，以及一段可以直接发给客户的文字（订阅链接、到期时间、流量、使用方法）。发之前可以先改，再点「复制话术」。

行尾的按钮：

| 按钮 | 作用 |
| --- | --- |
| 编辑 | 修改名称、到期、流量上限、IP 上限、重置日、备注。已用流量不在这里改 |
| 续费 | 见下文 |
| 停用 / 启用 | 停用后客户立即无法连接，订阅里会显示「账号已停用」 |
| 清零 | 把已用流量清零 |
| 重置链接 | 给这个用户换一条新的订阅链接和新密码，见下文 |
| 删除 | 删除用户，订阅立即失效 |

### 需要处理

用户列表上方会自动列出这些启用中的用户，最紧急的排在最前，每条后面都有「续费」按钮：

- 7 天内要到期的；
- 30 天内已经到期的；
- 流量用到 90% 以上的（月付用户会注明哪天自动重置）。

被你手动停用的用户不会出现在这里。

### 续费

点「续费」，填天数（也可以按套餐选），选择是否把已用流量清零，然后确认：

- 新的到期时间 = **当前到期时间和现在中较晚的那个** + 续费天数。提前续费，剩下的天数照算；过期后再续，从现在开始算，过期那几天不补。
- 续费会自动**启用**账号。
- 过期后再续费、且设了重置日的，重置日会改成续费当天（同一时刻），新周期从续费开始算；提前续费不改重置日。
- 不限期的用户续费不会加上到期时间，只按勾选清零流量。
- 订阅链接不变，客户不用做任何事。

### 重置链接

用于**某个用户的链接泄露、被转卖**的情况。点了之后：

1. 订阅链接换成新的，旧链接立即失效；
2. 连接密码也全部换掉，用旧链接导入的节点立即连不上。

所以要把**新链接**发给这个用户，让他删掉旧订阅、**重新导入**（只点「更新订阅」没用，因为旧链接已经失效了）。其他用户完全不受影响。

> 只是想让客户刷新节点列表时，**不要**点这个，让他在客户端里点「更新订阅」就行。

### 可用协议（入站分配）

点用户行里的「全部」或「3 / 8」进入：

- **全部入站（含以后新建）**：不限制，以后新建的入站也自动能用；
- **仅允许勾选项**：只能用勾选的入站，以后新建的入站不会自动加入。

顶部可以「全选当前入站 / 清空勾选」，每台节点也可以「全选 / 取消 / 仅选此节点」。比如只开放日本节点：在日本那一组点「仅选此节点」，再保存。不能保存为一个都不勾；要完全禁止使用，请停用用户。

### 同时在线 IP

按**不同的来源 IP** 计数，不是按连接数（一台设备会开几十条连接）。

- 超出上限时，**后连上来的那个 IP 会被断开**，先在用的不受影响。
- 一个 IP 断开后，名额会**再保留 1 分钟**。手机锁屏、断线重连都不会丢名额；从 WiFi 切到手机流量时，最多卡 1 分钟左右。
- **每台节点各自计数**。上限设 2 的用户，在两台节点上各用 2 个 IP 是允许的。所以用户列表里显示的 IP 数（各节点的总和）可能大于上限。
- 经过中转的连接，节点看到的都是中转机的地址，这时 IP 限制会变宽松，但不会误伤。

### 活动

显示用户每小时的**使用形态**：并发连接数、不同目标地址数、不同目标端口数、来源 IP 数，取每小时的峰值。

**不记录用户访问了哪些网站**，节点不上报，面板也不存。形态足够判断异常：正常浏览只连少数几个主机；BT 下载会同时连上百个不同的地址；长时间大流量下载则是「目标少 + 流量大」，可以对照流量一起看。

## 套餐

把常卖的组合保存成预设，比如「月付 100G / 3 个 IP / ¥30」。

| 字段 | 说明 |
| --- | --- |
| 名称 | 例如「月付 100G」，支持中文和空格 |
| 有效天数 | 留空或 0 表示不限期 |
| 流量上限、同时在线 IP、流量重置 | 同用户 |
| 备注 | 例如价格，会显示在下拉菜单里 |

新建用户或续费时选一个套餐，表单就会自动填好，填好后还能改。**用户和套餐之间不保留关联**：改价、改流量、删除套餐，都**不会影响已经开出去的账号**。

## 节点

一台代理服务器就是一个节点。安装方法见[安装](install.md#3-登记并安装节点)。

| 字段 | 说明 |
| --- | --- |
| 名称 | 支持中文。节点改名时，会自动按新名字重新生成它所有入站的名称 |
| 客户端连接地址 | 订阅里客户端要连接的地址（域名或 IP）。换服务器时只改 DNS 就行，不用重发订阅 |
| 国家 | 两位国家代码 |
| 流量倍率 | 扣多少套餐流量，见下表 |
| 订阅排序 | 数字越小，在订阅里越靠前（编辑时可改） |
| 节点统计重置 | 概览页「本周期」流量每月几号几点清零。只影响统计，不影响用户套餐和历史记录 |

**流量倍率**，以客户在这台节点上实际用了 100 GB 为例：

| 倍率 | 扣多少套餐流量 |
| --- | --- |
| `1` | 100 GB |
| `0.5` | 50 GB |
| `0` | 0 GB（不扣，但账号停用、到期、流量用完时依然不能用） |
| `2` | 200 GB |

可以填 0 到 100，最多三位小数。实际流量照常记录；改倍率只影响之后的流量，不会重算以前的，也不会重启节点。

客户看到的节点名会自动带上倍率，比如名称是「日本 Oracle 01」、倍率 0.5，订阅里显示为「日本 Oracle 01 [0.5×]」（1 倍不加后缀，不计流量显示 [0×]）。名称里已经手写了同样的后缀时不会重复添加。改了倍率后节点名随之变化，客户刷新订阅后，客户端里手动选中的节点可能需要重新选一次。

列表中的其他信息和按钮：

- **状态**：`在线` / `离线` / `已停用`。
- **入站**：入站数量，点进去管理这台节点的入站。
- **版本**：节点程序的版本 / 内核版本。
- **换 token**：生成新的接入 token，旧的立即失效。之后要把新 token 写进节点服务器的 `/opt/skysbx/node.env`（`SKYSBX_TOKEN=` 那一行），再执行 `systemctl restart skysbx-node`。
- **停用**：节点不再接受连接，也不出现在订阅里。

### 国内探针

节点被墙时，面板上一切看起来都正常：节点在线、有流量、入站已生效，只是国内的连接进不来。国内探针就是用来发现这种情况的。

1. 在国内找一台机器（轻量云、家里的软路由都行），像普通节点一样在面板新建节点、装节点程序。不用给它建入站。
2. 编辑这个节点，勾选「**国内探针**」。

之后面板每 5 分钟让探针对其他节点的 TCP 入站（VLESS Reality、AnyTLS、Shadowsocks）各试一次 TCP 握手，同时面板自己从海外也试一遍，并且两边都测一下节点的 22 端口作对照。结果显示在节点列表的状态栏和入站页：

| 显示 | 意思 | 怎么办 |
| --- | --- | --- |
| 国内可达 | 国内能连上 | — |
| 端口被封 | 这个端口国内不通，同一 IP 的其他端口是通的 | 换端口 |
| IP 的 TCP 被封 | 这个 IP 所有 TCP 端口国内都不通（ping 可能还通） | 换 IP，或改用 CDN 入站、Hysteria2 等 UDP 协议 |
| 部分探针不通 | 多台探针结果不一致 | 可能是个别运营商在干扰，继续观察 |
| 海外也连不上 | 面板从海外也连不上 | 节点本身或防火墙的问题，和墙无关 |

坏结果要连续两轮（约 10 分钟）一致才会显示，避免偶尔丢包误报。只测 TCP 握手，所以 UDP 协议（Hysteria2、TUIC）、经中转的入站和 CDN 入站不在探测范围内。结果只保存在内存里，面板重启后几分钟内会重新测出来。

## 入站

一个入站就是节点上的一个代理端口，在客户端里显示为一个节点。在节点列表点「入站」数量进入。

### 协议

| 协议 | 示例端口 | 防火墙要放行 | 要填的 | 适合 |
| --- | --- | --- | --- | --- |
| VLESS Reality | 443 | TCP | Reality 握手站点 | **主力**，最稳，不需要证书 |
| Hysteria2 | 8443 | UDP | 证书、SNI；可选混淆、伪装网站、跳端口 | 速度快；网络干扰 QUIC 时开混淆 |
| VLESS WS（CDN） | 2053 | TCP | CDN 域名；可选证书 | 节点 IP 被封时的**保底**，走 Cloudflare 等 CDN |
| AnyTLS | 8443 | TCP | 证书、SNI | 备用 |
| Shadowsocks 2022 | 8388 | TCP 和 UDP | 无（密钥自动生成） | 备用，兼容性最好 |
| TUIC v5 | 9443 | UDP | 证书、SNI | 一般不需要：功能是 Hysteria2 的子集（没有混淆、伪装、跳端口） |

建议每台节点至少开一个 **TCP** 协议（VLESS Reality）和一个 **UDP** 协议（Hysteria2），客户遇到哪种网络问题都有一个能用。

所有密钥、short id、Shadowsocks 的服务端密钥都自动生成。

### 通用字段

- **tag（入站名称）**：客户端里显示的名字，例如「香港 01」，支持中文，整个面板内不能重复。
- **端口**：同一台节点上同一个 TCP 端口不能被两个入站占用。和面板装在同一台机器时，要避开 80 和 443。
- **证书路径、私钥路径**：节点服务器上的文件位置，留空就是安装脚本放的 `/opt/skysbx/cert.pem` 和 `key.pem`。
- **SNI**：和节点证书匹配的域名，通常就是节点域名。
- **节点内排序**（编辑时可改）：同一节点内的排列顺序，数字越小越靠前。只改排序不会重启节点。

### VLESS Reality 的握手站点

Reality 会借用一个真实网站的 TLS 握手来伪装。可以从输入框旁的「常用站点…」下拉菜单里选，也可以自己填 `域名:端口`。

点「**检测**」会从面板确认这个网站支持 TLS 1.3 和 HTTP/2、证书正常。检测通过只代表从面板能连上，不代表每个地区都好用；检测不通过的网站肯定不能用。

### VLESS WS（CDN）

客户端连的是 CDN，CDN 再从海外连到节点。所以节点 IP 被墙（哪怕所有 TCP 端口都不通）时，这个入站照样能用；代价是速度和延迟取决于 CDN 到国内的线路。

以 Cloudflare 为例：

1. 域名托管在 Cloudflare，给节点加一条 A 记录（比如 `cdn.example.com` → 节点 IP），**打开代理**（橙色云朵）。
2. 「SSL/TLS」模式选 **Full (strict)**。节点上的证书要对这个域名有效：安装脚本申请的证书（节点域名就是 CDN 域名时）或 Cloudflare 签发的 Origin 证书都可以，后者把路径填进「证书路径」「私钥路径」。
3. 新建入站选 `vless-ws`，端口用 Cloudflare 支持的 HTTPS 端口：443、2053、2083、2087、2096、8443。「CDN 域名」留空就是节点地址。
4. 想让客户端连优选过的 Cloudflare IP，把 IP 填进「外部中转地址」；TLS 和 Host 仍然用 CDN 域名。

WebSocket 路径自动生成，编辑入站时保持不变，相当于一个共享密钥：猜不到路径的人只会看到 404。订阅里三种格式（Clash / mihomo、sing-box、分享链接）都带上了路径、Host 和 early data。

### Hysteria2：混淆和伪装网站

两个功能防的是两种不同的情况：

- **混淆（salamander）**：给每个数据包再套一层，让流量**看起来不像 QUIC**。适合「HY2 时好时坏、经常超时，换成 Reality 就正常」的情况，也就是客户的网络在限速或干扰 QUIC。混淆密码自动生成并写进订阅，Clash Verge / mihomo、sing-box、Shadowrocket 都支持。
- **伪装网站**：有人用浏览器或探测程序访问这个端口时，看到的是这个网站（比如 bing.com），而不是一个暴露代理身份的错误。只影响服务器端，客户端不用变。可以从下拉菜单选、点「随机」，或者填任意 https 网址；不同入站最好用不同的网站。

**两者是二选一生效的**：开了混淆，探测者连握手都完成不了，到不了伪装网站这一步，所以伪装填不填都行（留着不碍事，以后关掉混淆就会生效）。

| 情况 | 选择 |
| --- | --- |
| HY2 经常超时，Reality 正常 | 开混淆 |
| HY2 用着正常，只想更不容易被识别 | 不开混淆，填伪装网站 |

### Hysteria2 跳端口

例如：监听 `8443`，跳跃范围 `20000-30000`，间隔 `30s`。客户端会在这个范围里不停换端口，避开对单个 UDP 端口的限速。

1. 云安全组放行 UDP 8443 和 UDP 20000–30000，本机防火墙允许 UDP 8443；
2. 节点会自动把整个范围转发到监听端口（需要 nftables，安装脚本已装好）；
3. 客户更新订阅。

范围可以写 `20000-30000,40000`，不能和其他入站或中转端口重叠。清空范围就是关闭。只支持直连的 Linux 节点，不能和中转一起用。

### 中转

两种方式，二选一：

- **站内中转**：选另一台由面板管理的节点当中转机，面板会自动在它上面开一个转发端口，把流量原样转到本节点。不解密、不认证，所以流量统计、IP 限制、活动记录都不受影响。修改中转只会重建中转机的配置。
- **外部中转地址**：中转机不归面板管（例如自己配的 realm、nginx stream），填 `relay.example.net:443`，带上中转机监听的端口。

### 状态

| 状态 | 意思 |
| --- | --- |
| `已生效` | 节点正在用最新的设置运行这个入站 |
| `确认中…` | 设置刚发给节点，页面会自动刷新等它确认 |
| `等待节点应用` | 节点还在用旧的设置，一直没跟上 |
| `跑的是旧配置` | 节点拒绝了最新的配置，仍在跑上一份，页面顶部会显示原因 |
| `未生效` | 节点没有运行这个入站，查看页面顶部的错误和节点日志 |
| `节点离线` | 节点没连上面板，无法确认 |

### 修改入站的注意事项

- 新增、修改、停用任何入站，都会**重建这台节点的配置，节点上所有客户都会断线一次**。
- **改握手站点、开关混淆、改端口，客户在更新订阅之前会一直连不上。**正在使用的入站不要直接改：新建一个入站和旧的并行运行一两周，大部分客户更新过订阅后再停用旧的。
- 改伪装网站、改证书路径、改名称、改排序不影响客户端。

## 限制

对**所有节点、所有用户**生效的使用限制：

- **禁止 BT / PT**：能拦住明文 BT、uTP 和 UDP tracker，也就是大部分 BT 流量；拦不住走 TCP 的加密 BT。效果是让 BT 很难用，不是完全不能用。
- **禁止测速站点**：按域名拦截常见测速网站。
- **自定义域名黑名单**：每行一个，按后缀匹配。写 `example.com` 会把 `a.b.example.com` 一起拦掉。

保存会给**所有节点**推送新配置，所有连接会断一次。开启任何一项后，节点会检查每条连接开头的几个字节来判断协议和域名。

「大流量下载」没有开关，它是用量问题，用用户的流量上限和同时在线 IP 来管。

## 设置

### 面板访问路径、根域名跳转

见[安装：隐藏后台地址](install.md#隐藏后台地址推荐)。

### 订阅公告

每行一条（最多 5 行，每行不超过 60 个字），会显示在**每个客户订阅的节点列表最上面**，比如「📢 官网：example.com」「续费请联系：xxx」。留空保存就是关闭。

公告是连不上的假节点，只用来显示文字。在 Clash、sing-box 里，公告单独放在最上面的「公告」分组，**不会进入任何真正走流量的分组**，客户不会误连。客户要更新订阅才能看到新公告。公告不能和分组同名（如「AI」「节点选择」），同名的那行会被跳过。

### 更换域名

在「设置 → 更换域名」里填新的面板域名（和订阅域名，可选），点「更换域名」。

1. **先**在域名服务商那里把新域名的 A 记录指向面板服务器。面板会检查解析，没指向这台服务器会提示你，不会保存。用了 CDN 或检查误报时，可以勾「跳过解析检查」；
2. 保存后面板自动重启，十几秒到一两分钟后用新域名打开（第一次要申请证书）。新域名暂时打不开时，旧地址仍然可以登录；
3. 节点会自动改连新域名，并记到节点自己的配置里，**不用登录节点服务器**。需要节点是这个版本或更新的，旧节点先升级；
4. 面板服务器上的那台节点，如果地址就是面板域名，会自动换成新域名和新证书。用它的 AnyTLS、Hysteria2、TUIC 的客户要**更新一次订阅**；
5. 新复制的订阅链接都是新域名。**旧域名继续保留**，已经发出去的旧订阅链接照样能用。

等节点都切过去（页面会显示还有几个节点连着旧域名）、客户都换了新链接，再点「停用旧域名」。停用后旧域名上的链接失效，面板也不再给它续证书。旧域名被封或过期了也没关系，它保留着只是不起作用。

### 两步验证

开启后，登录除了密码，还要输入手机验证器（Google Authenticator、Microsoft Authenticator、1Password 等）上的 6 位数字。

1. 点「开启两步验证」，用验证器扫二维码；
2. 输入验证器显示的 6 位数字确认。输对之前不会生效，扫错了也不会把自己锁在外面；
3. **保存好页面显示的 10 个恢复码**，只显示这一次。手机丢了时，每个恢复码可以代替验证码登录一次。

关闭两步验证或重新生成恢复码，都需要输入当前的验证码。**手机和恢复码都丢了**时，在面板服务器上执行：

```bash
/opt/skysbx/skysbx-panel -db /opt/skysbx/skysbx.db -reset-2fa
```

或者运行 `veyra` 菜单 → Panel → 7。

### 强制全员更新订阅

紧急情况用的按钮，**平时不要点**。需要输入「全部断连」确认。

- 所有用户的连接密码全部换新，**订阅链接不变**；
- 每台节点重建配置，所有连接断开；
- 客户在客户端点「更新订阅」后恢复。很多客户端会自动更新（面板建议的间隔是 12 小时），没手动更新的客户最多可能断 12 小时左右，所以最好提前通知客户。

适合：怀疑某台节点服务器被别人拿到、删掉了一台不再信任的节点、怀疑大量配置被泄露。

| 情况 | 用哪个 |
| --- | --- |
| **某一个**用户的链接泄露 | 用户页的「重置链接」 |
| 怀疑**所有人**的配置都泄露了 | 强制全员更新订阅 |
| 只是想让客户刷新节点列表 | 都不用，让客户自己点「更新订阅」 |

## 订阅和客户端

### 导入

把用户的订阅链接粘贴到客户端，作为「订阅」导入并更新。面板会根据客户端自动选择格式，也可以在链接后面加参数指定：

| 客户端 | 导入方式 | 指定格式 |
| --- | --- | --- |
| Clash Verge / Clash Party / mihomo | 导入远程订阅 | `?format=clash` |
| sing-box | 远程配置 | `?format=singbox` |
| Shadowrocket（小火箭） | 添加订阅 | `?format=shadowrocket` |
| v2rayN 等 | 添加订阅分组 | `?format=base64` |

用浏览器打开订阅链接，看到的是一串 Base64 文字，这是正常的。

### 订阅里有什么

- 用户能用的所有入站，按节点的「订阅排序」和入站的「节点内排序」排列；
- Clash 和 sing-box 格式里，有一套现成的分组和分流规则，见下面的[分组和分流](#分组和分流)；
- 已用流量、总流量和到期时间：大多数客户端会显示在订阅信息里，小火箭显示为「上传 / 下载 / 总量 / 到期」；
- 设置了[订阅公告](#订阅公告)时，公告在最前面。

账号停用、到期或流量用完时，订阅仍然能正常更新，但里面只有一条写着原因的提示（例如「已于 2026-11-10 到期，请联系续费」），后面跟着订阅公告。客户一看就知道该联系你，不会以为是软件坏了。

### 分组和分流

Clash 和 sing-box 格式的订阅自带以下分组，客户在客户端里可以逐个切换：

| 分组 | 默认 | 管哪些流量 |
| --- | --- | --- |
| 公告 | — | 只在设置了订阅公告时出现，只用来显示文字 |
| 节点选择 | 第一个节点 | 主开关，列出全部节点 |
| AI | 跟随节点选择 | ChatGPT、Claude、Gemini 等 |
| YouTube | 跟随节点选择 | |
| Netflix | 跟随节点选择 | |
| 谷歌 | 跟随节点选择 | 搜索、Gmail、Google Play 等 |
| 苹果 | 直连 | App Store、iCloud、系统更新 |
| 微软 | 直连 | Windows 更新、Office、Bing 等 |
| 漏网之鱼 | 跟随节点选择 | 上面都没匹配到的其他流量 |

- **国内网站和国内 IP 固定直连**，不走节点，不消耗套餐流量；局域网地址也直连。GitHub 跟随「节点选择」。
- 没有「自动选择」：节点坏了不会自动切换，客户要手动换一个。
- 每个分组各自选节点，各管各的流量。比如 AI 选美国、Netflix 选新加坡、其他走香港时，三个节点同时在用；流量按各节点的倍率计算后，扣的是同一个套餐。
- 分流规则来自 [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat)。客户端通过订阅地址下的 `/sub/rules/` 从面板下载规则文件，每天自动更新；面板每 12 小时从 GitHub 同步一次。所以客户在国内连不上 GitHub 也不影响，你不需要维护任何名单。
- Shadowrocket 和 v2rayN 用的是分享链接，带不了分组和规则，分流由客户端自己的设置决定（v2rayN 自带「绕过大陆」，Shadowrocket 可以另外添加规则配置）。

### 安全

订阅链接就等于账号密码：Base64 不是加密，拿到链接的人可以直接导入使用。不要公开分享。链接泄露时用「重置链接」。

### 单独的订阅域名

安装时可以设置一个单独的订阅域名（如 `sub.example.com`）。设置后，只有这个域名能访问订阅，访问它的其他路径（包括 `/login`）都返回 404；面板后台仍然用面板域名。

## 哪些操作会断线

| 操作 | 影响 |
| --- | --- |
| 新增 / 修改 / 停用用户、续费、清零、重置链接 | 不重启任何东西，其他人的连接照常 |
| 改节点的倍率、连接地址、排序、统计重置 | 不影响连接 |
| 节点改名（会连带重命名它的入站） | 这台节点上所有连接断一次 |
| 新增 / 修改 / 停用入站 | 这台节点上所有连接断一次 |
| 保存「限制」页 | 所有节点的所有连接断一次 |
| 强制全员更新订阅 | 所有连接断开，客户更新订阅后才能恢复 |
| 升级面板 | 后台几秒钟打不开，**客户连接不受影响** |
| 升级节点 | 这台节点的连接断一次 |
